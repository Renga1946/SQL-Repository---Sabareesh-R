# 🍕 Pizza Sales SQL Analysis

This repository showcases a comprehensive SQL-driven analysis of pizza sales data to uncover business insights, performance KPIs, and customer ordering patterns.

## 📊 Projects

*   **Pizza Sales Analysis:** A deep dive into transactional data to calculate revenue, identify top-selling products, and analyse peak sales periods using advanced SQL queries.

## 🚀 Key Features

To drive business decisions, the following metrics were calculated:
*   **KPI Tracking:** Total Revenue, Average Order Value, and Total Pizzas Sold.
*   **Trend Analysis:** Daily and Monthly sales patterns to optimize staffing.
*   **Product Performance:** Sales distribution by Pizza Category and Size.
*   **Inventory Insights:** Top 5 and Bottom 5 best-sellers to manage stock.

## 🛠️ Tools Used

*   **SQL:** For complex data querying and transformation.
*   **MS SQL Server / MySQL:** As the primary database engine.
*   **Excel/CSV:** For initial data sourcing and verification.

## 📁 How to Use

1.  Clone this repository to your local machine.
2.  Import the `Pizza_Sales_CSV.sql` to set up your database schema.
3.  Run the `Pizza_Sales_Recall.sql` script to generate the analysis reports.
