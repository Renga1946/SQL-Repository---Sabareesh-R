# Pizza Sales Analysis Project

## Project Goal
The goal of this project is to analyse pizza sales data using SQL JOINS to connect order details with product information.

## My Process
1. **Data Setup**: I created a database called `pizza_sales_capstone`.
2. **Table Creation**: I imported two tables: `pizza_sales` (transaction data) and `pizzas` (product details).
3. **Data Connection**: I practised various JOINs (INNER, LEFT, RIGHT) to link these tables using the `pizza_id`.

## Key Learnings
* **INNER JOIN**: Shows only the successful matches between sales and products.
* **LEFT JOIN**: Ensures I see every sale, even if product info is missing.
* **Database Referencing**: I learned to use `database_name.table_name` to avoid errors in MySQL Workbench.
